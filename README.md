# animace

Animace ve stylu Vox – HTML/SVG scény renderované přes Playwright + ffmpeg.

```bash
S=.claude/skills/vox-animation/scripts
node $S/render.mjs .claude/skills/vox-animation/examples/demo.html --contact 12   # náhled
node $S/render.mjs .claude/skills/vox-animation/examples/demo.html --out out/demo.mp4
```
